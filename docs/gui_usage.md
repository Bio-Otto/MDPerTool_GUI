# GUI Interface

The Graphical User Interface provides an intuitive way to configure your OpenMM Perturbation simulations.

## Main Dashboard
- **Input PDB / Trajectory**: Select your structural files.
- **Forcefield Settings**: Configure protein and water forcefields.
- **Perturbation Residues**: Choose which residues to perturb.

> Keep in mind that when using the GUI, all required dependencies must be loaded correctly, mainly GUI relies on PySide2 and pyqtgraph libraries.
