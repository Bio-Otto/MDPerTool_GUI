# Welcome to MDPerTool

**MDPerTool (Molecular Dynamics Perturbation Tool)** is a Software Tool for Investigation of Allosteric Communication within Protein Structures via Energy Dissipation in Molecular Dynamics Simulations.

## Features
- **Energy Dissipation Concept:** Apply energy dissipation using the powerful OpenMM Molecular Dynamics Toolkit.
- **CUDA Support:** Fully supports CUDA platforms for high-performance simulations.
- **Flexible Ecosystem:** Perform residual energy calculation via OpenMMs flexible infrastructure.
- **Trajectory Decomposition:** Use the package strictly for energy decomposition by specifying an XTC or DCD file.
